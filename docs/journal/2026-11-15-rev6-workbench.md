# rev6 工作台本地候选

用户要求沿用独立 Git 仓库，视觉与交互以 VS Code 和 Codex 插件为准；默认“Codex 聊天居中，文件和编辑器按需打开”。

## 实现

复用已有会话、工具、编辑器与终端模块，替换工作台布局和视觉。标题栏接入实际命令面板，活动栏集中导航，状态栏显示实际连接状态。终端移到底部并在隐藏后保留实例，桌面文件树使用名称列表，不改写全屏文件视图偏好。保留系统主题、手机导航、会话重命名与失联提示。

版本元数据准备为 `1.37.8-rev.6`。没有发布 tag、GitHub Release、远端 push 或线上部署。

当前为本地 UI 候选，发布前仍需确认后端回归状态和实际服务体验。独立审查发现的终端后台连接、活动栏裁剪和终端 Ctrl+J 冲突已复现并修复，处置见 [审查记录](../reviews/2026-11-15-rev6-workbench.md)。修复后前端全测、类型检查、lint 和完整构建均退出 0；浏览器确认隐藏切会话不连接、所有插件与底部设置可达、Ctrl+J 不产生终端输入。
