# rev6：VS Code 工作台与 Codex 中央对话

## 目标与来源

| 项目 | 本会话原话 / 边界 |
| --- | --- |
| 需求 | 用户：「界面太乱了 UI 视觉效果 逻辑 要完全复制vscode，主要是vscode,以及codex插件」 |
| 动机 | 用户：「界面太乱了」 |
| 完成标准 | 用户选择：「Codex 聊天居中，文件和编辑器按需打开」；外层视觉和工作台交互采用 VS Code，中央聊天采用官方 Codex 扩展的组织方式。 |
| 边界 | 本地准备 rev6 UI；保留现有聊天、工具、会话、文件编辑和终端实现。发布和线上部署分别执行。 |

## 参考

本机 VS Code 1.145.3 的 Dark Modern / Light Modern 主题；官方 Codex 扩展
`openai.chatgpt` 26.1111.21308。以它们的密度、分区、边框、工具按钮和信息层级为准。
保留 Cloud Cli rev 产品身份，不使用 VS Code 商标冒充官方产品。

## 工作台

- 顶部 35px 标题栏：项目名称与命令中心、布局开关。命令中心打开现有命令面板。
- 桌面左侧 48px 活动栏：对话、资源管理器、源代码管理、可用的任务/浏览器/插件；设置在底部。
- 默认左侧为紧凑的项目/会话列表，中央始终以聊天为主要内容。活动栏再次点击当前入口可收起侧栏。
- 文件入口按需打开文件树；点击文件沿用现有编辑器，在右侧打开，可关闭、展开、调整宽度。
- 终端为独立的底部面板，打开/关闭不切走聊天，也不卸载聊天。隐藏终端保留已挂载实例。
- 源代码管理、任务、浏览器和插件继续使用现有实现；入口集中到活动栏，避免顶部重复导航。
- 底部 22px 状态栏显示真实连接状态、项目路径和终端开关，不添加虚构的分支、诊断或运行数据。
- 现有 Cmd/Ctrl+K 保留，同时支持 VS Code 的 Cmd/Ctrl+Shift+P；Cmd/Ctrl+J 切换底部面板。
- 手机保留可触达的紧凑导航和侧栏抽屉，不强行挤入桌面多栏。

## 视觉

Dark Modern：编辑区域 `#1f1f1f`，侧栏/标题栏/面板 `#181818`，边框 `#2b2b2b`，
正文 `#cccccc`，辅助文字 `#9d9d9d`，强调色 `#0078d4`。
Light Modern：编辑区域 `#ffffff`，外框 `#f8f8f8`，边框 `#e5e5e5`，
正文 `#3b3b3b`，强调色 `#005fb8`。保留现有跟随系统/深色/浅色选择。

使用系统 UI 字体、13px 工作台文字、紧凑行高、单像素边框。导航使用矩形选中态和蓝色细线。
移除工作台的玻璃模糊、发光胶囊、渐变分隔、宣传徽章和重复页脚入口。
聊天保留清楚的消息分组与可折叠工具，输入框采用 Codex 的克制边框、紧凑控件和单一发送主按钮。
所有既有模型、权限、附件、Steer/排队、工具和发送行为继续工作。

## 实现选择（实现者决定）

复用 React、Tailwind、Lucide、CodeMirror、xterm 和现有模块，不新增运行依赖。
最短路径是重新组织现有工作台和统一设计变量，不嵌入 VS Code，也不重写模型/终端后端。
终端开关放在 project-workspace 自有布局 context，避免把短期布局状态写入会话状态。
命令面板使用可控 open 回调连接标题栏，保留原有热键兼容。
